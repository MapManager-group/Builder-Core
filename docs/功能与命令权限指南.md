# BuilderCore 功能与命令权限指南

本文依据当前 `src/main/resources/plugin.yml`、`config.yml` 和 Java 实现整理。命令中的 `<参数>` 表示必填，`[参数]` 表示可选；以 `//` 开头的 WorldEdit 快捷命令需按两个斜杠输入。命令可见性受 `plugin.yml` 的 `permission` 控制，部分命令还有源码中的细分权限检查。

## 功能概览

- **建筑环境**：按权限保护方块与实体；可配置关闭红石、重力物理、爆炸、树叶衰减、耕地踩踏和龙蛋传送。建筑工具菜单包含能力开关、皮革护甲配色、旗帜编辑、特殊物品和周边区块刷新。
- **玩家工具**：飞行、速度、游戏模式、个人/世界时间与天气、夜视、穿墙、进阶飞行、半砖破坏、交互距离、尺寸、调试棒、玩家头颅和物品编辑。
- **传送与位置**：玩家/坐标传送、传送请求、传送屏蔽、返回历史、私人家和公共传送点。TP/TPA 可通过 `teleport.check-mmc-permissions` 开启 MMC v4 权限检查。
- **管理与社交**：隐身、查看背包/末影箱、查询玩家、AFK、可选的用户协议确认，以及在 PlaceholderAPI 启用时注册的占位符/自动 AFK 功能。WorldEdit 快捷命令需服务器具备对应的 WorldEdit 命令。

## 命令指南

### 传送、家与传送点

| 命令                                                                      | 功能                                                          | 权限                                                                                                                                    |
|---------------------------------------------------------------------------|---------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------|
| `/tp <玩家>`                                                              | 传送到在线玩家                                                | `buildercore.commands.tp` + `buildercore.commands.tp.player`                                                                            |
| `/tp <玩家A> <玩家B>`                                                     | 将 A 传送至 B                                                 | `buildercore.commands.tp` + `buildercore.commands.tp.player` + `buildercore.commands.tp.other`                                          |
| `/tp <x> <y> <z>`                                                         | 传送自己到坐标，支持 `~` 相对坐标                             | `buildercore.commands.tp` + `buildercore.commands.tp.location`                                                                          |
| `/tp <玩家或@s> <x> <y> <z>`                                              | 将指定玩家传送到坐标                                          | `buildercore.commands.tp` + `buildercore.commands.tp.location`；目标不是自己时还需 `buildercore.commands.tp.other`                      |
| `/tphere <玩家>`                                                          | 将指定玩家传送到自己身边                                      | `buildercore.commands.tphere`                                                                                                           |
| `/tpa <玩家>`、`/tpahere <玩家>`                                          | 请求传送到对方 / 请求对方传送过来                             | `buildercore.commands.tpa`                                                                                                              |
| `/tpaccept`、`/tpdeny`                                                    | 接受 / 拒绝待处理传送请求                                     | `buildercore.commands.tpa`                                                                                                              |
| `/tpignore`                                                               | 切换是否屏蔽强制传送                                          | `buildercore.commands.tpignore`                                                                                                         |
| `/back [步数]`                                                            | 返回历史位置；默认返回上一个位置，记录数由 `backHistory` 控制 | `buildercore.commands.back`                                                                                                             |
| `/sethome <名称>`、`/delhome <名称>`                                      | 设置 / 删除自己的家                                           | `buildercore.commands.sethome` / `buildercore.commands.delhome`                                                                         |
| `/home <名称>`、`/homes`                                                  | 传送到家 / 列出家                                             | `buildercore.commands.home` / `buildercore.commands.homes`                                                                              |
| `/sethome <玩家>:<名称>`、`/delhome <玩家>:<名称>`、`/home <玩家>:<名称>` | 管理或访问其他玩家的家                                        | 各命令基础权限 + 对应的 `buildercore.commands.sethome.other` / `buildercore.commands.delhome.other` / `buildercore.commands.home.other` |
| `/warps`、`/warp <名称>`                                                  | 列出可用传送点 / 前往传送点                                   | `buildercore.commands.warps` / `buildercore.commands.warp`                                                                              |
| `/setwarp <名称> [显示别名]`、`/delwarp <名称>`                           | 设置 / 删除公共传送点                                         | `buildercore.commands.setwarp` / `buildercore.commands.delwarp`                                                                         |

传送请求有有效期；`/warps` 仅展示有目标世界访问权限的传送点。家与传送点名称的校验由 `illegal-characters` 配置决定，默认格式为英文字母开头、后接英文字母或数字。

## 权限配置

`plugin.yml` 提供下列权限包；建议在权限插件中授予权限包，再按需增加细分权限。

| 权限包                      | 包含的主要能力                                            |
|-----------------------------|-----------------------------------------------------------|
| `buildercore.pack.teleport` | 家、返回、传送点、传送屏蔽，以及 `/tp` 的基础和坐标权限   |
| `buildercore.pack.warpset`  | 设置、删除公共传送点                                      |
| `buildercore.pack.public`   | 建筑保护权限、传送包、传送请求、建筑工具、个人天气/时间等 |
| `buildercore.pack.private`  | 公共包同类建筑工具与传送能力，另含世界时间/天气等         |
| `buildercore.admin`         | 管理命令及部分管理权限，默认仅 OP                         |

`buildercore.protect.*` 用于建筑保护，源码实际检查 `break`、`place`、`interact`、`lectern`、`ignite`、`sign`、`item_frame`、`farmland`、`armor_stand`。旁观控制使用 `buildercore.spectate.player`、`.entity`、`.teleport`；另一个传送监听器还检查 `buildercore.event.spectate`。`buildercore.afk.bypass` 绕过自动 AFK，`buildercore.blocked.bypass` 绕过受限命令拦截，`buildercore.service.quickopen` 控制快速打开容器。`buildercore.spectate.*` 在 `plugin.yml` 中默认授予所有玩家，其余未显式定义的细分节点应由权限插件按需授予。

**权限包并不覆盖所有细分检查。** 例如管理其他玩家的 `/tp`、游戏模式、速度或飞行，需额外授予对应 `.other` 节点。BuilderCore 不再检查 Multiverse 的世界进入权限节点。`buildercore.admin` 的子权限也不等于所有命令权限。

## 配置与依赖

- `config.yml` 的 `building-settings` 控制建筑环境开关；`special-items` 定义特殊物品菜单内容；`backHistory` 控制返回历史条数；`afk.threshold` 是自动暂离时间。
- `agree.agreement` 默认关闭。启用前需填写协议 URL 与 `database` 的 MySQL 连接信息；启用后才注册 `/agree` 和 `/disagree`。
- `teleport.check-mmc-permissions` 默认 `true`，重载配置后生效。关闭或未安装 MMC 时，TP/TPA 只检查原有命令权限；开启且 MMC 已启用时，直接 TP（含坐标、`tphere`）检查实际移动玩家在目标地图的 ADMIN/BUILDER 角色，TPA（含 `tpahere`）检查实际移动玩家的 MMC 准入结果（包括公开地图）。同世界传送也检查，未登记为 MMC 地图的世界允许；MMC 服务未就绪或检查异常时拒绝。TP 延迟执行与 TPA 接受时重新检查；原有 `/tpignore` 屏蔽规则保留。
- 传送点的使用、列表和删除不再检查 Multiverse 权限，保留各自命令权限；服务器其他插件仍可能限制实际传送。
- 编译前需在 MMC v4 源码目录运行 `mvn -pl api -am install` 安装 `mapmanager-api:4.0.0-SNAPSHOT`；API 为 provided 依赖，不打入 BuilderCore JAR。
- `plugin.yml` 将 PlaceholderAPI、floodgate 和 MapManager-Core 列为软依赖。PlaceholderAPI 未启用时，占位符扩展与自动 AFK 监听器不会注册。
- 插件使用 Paper API，`pom.xml` 目标为 Java 21 / Paper 1.21；相关 WorldEdit 快捷命令依赖服务器实际提供 WorldEdit 命令。

权限矩阵可通过 `python3 src/test/check_teleport_access.py` 运行，覆盖 MMC 角色、开关、服务未就绪/撤销及未安装 MMC API；该检查不替代真实服务器的命令与传送事件验证。

本文描述的是当前源码行为。新增或修改命令时，应同时核对 `plugin.yml` 声明、`BuilderCore.registerCommands()` 注册及执行器内部权限检查。
