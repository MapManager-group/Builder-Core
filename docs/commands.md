# 命令手册

[返回目录](../README.md) · [权限配置](permissions.md)

`<参数>` 必填，`[参数]` 可选，`|` 表示任选一项。命令支持按前缀补全，玩家名补全隐藏不可见玩家。固定参数和无参数命令可用 `--help` 查看帮助；自由名称和 WorldEdit 转发参数保留字面含义。管理员可用 `/buildercore help [页码或命令]` 查完整用法。

大部分命令仅玩家可用。控制台支持 `/buildercore`、`/whois`，以及指定目标的 `/fly`、`/speed`、`/gamemode`、`/ptime`、`/tp`。

## 建筑工具与物品

| 命令 | 用途 |
| --- | --- |
| `/buildertools [ability\|armorcolor\|banner\|special\|rc]`（`/btools`） | 默认打开能力菜单；其余为护甲配色、旗帜、特殊物品及区块刷新 |
| `/armorcolor`、`/banner` | 直接打开配色器、旗帜编辑器 |
| `/cushiontools` | 切换坐垫工具模式，再次执行恢复背包 |
| `/slab`（`/sb`） | 切换双层半砖的半层破坏 |
| `/debugstick`（`/dbs`） | 获取调试棒 |
| `/head <玩家>`（`/skull`） | 获取玩家皮肤头颅 |
| `/hat` | 交换主手物品与头盔栏 |
| `/itemname <名称>`（`/iname`） | 修改主手物品名，支持 `&` 颜色代码，名称限一个参数 |
| `/itemcolor <六位十六进制 RGB>`（`/icolor`） | 设置皮革物品颜色，可带 `#`，如 `/itemcolor #66CCFF` |
| `/itemnbt`（`/inbt`） | 查看物品元数据并点击复制 |

菜单和交互操作见[建筑交互](features.md)，坐垫工具见[坐垫工具](features.md#坐垫工具)。`rc` 只刷新已加载区块，半径取客户端视距、世界视距和 8 的最小值。

## 玩家状态

| 命令 | 用途 |
| --- | --- |
| `/fly [玩家]` | 切换飞行许可 |
| `/speed <速度>`、`/speed <walk\|fly> <速度> [玩家]` | 设置速度，范围 0.1–10；单参数按当前是否飞行选择类型 |
| `/gamemode <模式> [玩家]`（`/gm`） | 切换游戏模式 |
| `/reach [距离]` | 方块交互距离 0–64；不填重置为 4.5 |
| `/scale [倍数]` | 尺寸倍数 0.0625–16；不填重置为 1 |
| `/advfly`（`/af`） | 切换进阶飞行，减少停止时的水平惯性 |
| `/noclip`（`/nc`） | 切换自动穿墙，在创造和旁观模式间转换 |
| `/night`（`/nv`、`/n`） | 切换永久夜视 |
| `/afk` | 手动切换暂离状态并广播 |

模式可用 `survival/s/0`、`creative/c/1`、`adventure/a/2`、`spectator/sp/3`。进阶飞行不授予飞行许可；自动穿墙在靠近实心方块时进入旁观，脱离后恢复创造，在实心方块上潜行也会触发。

## 家与公共传送点

| 命令 | 用途 |
| --- | --- |
| `/sethome <名称>`、`/delhome <名称>` | 在当前位置设置家 / 删除家 |
| `/home <名称>`、`/homes` | 前往家 / 查看可点击的家列表 |
| `/sethome <玩家>:<名称>`、`/delhome <玩家>:<名称>`、`/home <玩家>:<名称>` | 设置、删除或访问指定玩家的家 |
| `/setwarp <名称> [别名]`、`/delwarp <名称或别名>` | 设置、删除公共传送点 |
| `/warp <名称或别名>`、`/warps` | 前往公共传送点 / 按世界列出已加载的传送点 |
| `/back [步数]` | 返回历史位置，默认 1 步；失败保留记录，离线清空，不单独记录死亡位置 |

名称限一个参数，支持中文和点号；家名按小写保存。同名位置不能用命令直接覆盖，传送点别名不能与已有名称或别名冲突。为他人设置家时保存执行者的位置，数量规则见[家数量](permissions.md#家数量)。目标世界未加载时仍可删除记录。

家、公共传送点和返回不执行 TP/TPA 的 MMC 检查；`/warps` 也不按世界准入权限过滤。

## 玩家与坐标传送

| 命令 | 用途 |
| --- | --- |
| `/tpa <玩家>`、`/tpahere <玩家>` | 请求传送到对方 / 请求对方传送过来 |
| `/tpaccept`、`/tpdeny` | 接受 / 拒绝请求 |
| `/tp <玩家>` | 传送到在线玩家 |
| `/tp <玩家A> <玩家B>` | 将 A 传送至 B，控制台可用 |
| `/tp <x> <y> <z>` | 将自己传送到坐标 |
| `/tp <玩家或@s> <x> <y> <z>` | 将指定玩家传送到坐标，控制台需指定玩家名 |
| `/tphere <玩家>` | 将对方传送到自己身边 |
| `/tpignore` | 切换是否屏蔽别人用单参数 `/tp <玩家>` 传送到自己身边 |

TPA 有效期 60 秒，每个接收者保留最新一条请求。单玩家和双玩家 `/tp` 延迟 1 秒；坐标 TP、`/tphere` 和 TPA 无此延迟。世界准入规则见 [MapManager v4](installation.md#mapmanager-v4)。`tpignore` 不拦截双玩家 TP、坐标 TP、`tphere` 或 TPA，离线清除。

坐标支持数值和 `~` 相对坐标，不支持 `^`。四参数 TP 使用被移动玩家的世界，相对坐标以执行玩家为基准；控制台执行时以被移动玩家为基准。

## 时间与天气

| 命令 | 用途 |
| --- | --- |
| `/time <时间>`、`/time set <时间>`、`/time add <非负整数>` | 设置或增加当前世界时间，数值单位为 tick |
| `/ptime <时间\|reset> [玩家]` | 设置固定个人时刻，`reset` 恢复跟随世界时间 |
| `/weather <clear\|rain\|thunder>` | 设置当前世界天气 |
| `/pweather <clear\|rain\|reset> [玩家]` | 个人晴天 / 降雨 / 恢复跟随世界天气 |

时间可用数值或 `sunrise`、`day`、`morning`、`noon`、`afternoon`、`sunset`、`night`、`midnight`。`time` 和 `weather` 影响同世界玩家；`pweather` 仅玩家可执行。

## 管理与协议

| 命令 | 用途 |
| --- | --- |
| `/buildercore help [页码或命令]` | 查看命令帮助 |
| `/buildercore info`、`/buildercore reload` | 查看插件信息 / 重载配置 |
| `/whois <玩家>` | 查看在线玩家的 IP、UUID、位置和状态，控制台可用 |
| `/invsee <玩家>`、`/endersee [玩家]` | 打开在线玩家背包 / 自己或在线玩家的末影箱，可操作实际库存 |
| `/vanish` | 向其他玩家隐藏自己并添加隐身效果，尝试开启 `tpignore`；退出不恢复原屏蔽状态 |
| `/agree`、`/disagree` | 同意 / 拒绝用户协议，仅启用协议时可用 |

## WorldEdit 快捷命令

需要 WorldEdit 的相应命令和权限，另需 BuilderCore 的[快捷命令权限](permissions.md#命令权限)。

| 命令 | 转发或操作 |
| --- | --- |
| `//p1 [坐标]`（`//1`）、`//p2 [坐标]`（`//2`） | `//pos1`、`//pos2`，保留后续参数 |
| `//pa`、`//s`、`//r`、`//f`、`//c` | `//paste`、`//set`、`//replace`、`//flip`、`//copy`，保留后续参数 |
| `//derot <x\|y\|z> <整数角度>` | 绕轴旋转选区 |
| `//twist <x\|y\|z> <整数角度>` | 沿轴扭转选区 |
| `//scale <非零数值>` | 缩放选区，区别于调整玩家尺寸的 `/scale` |
| `//cuboid`（`//cub`）、`//convex`（`//con`） | 切换选区模式 |
| `/undo`（`/u`） | 撤销一次，不转发额外参数 |

`worldedit-extra-aliases` 只控制前两行快捷命令，形变、选区模式和撤销快捷命令始终注册。
