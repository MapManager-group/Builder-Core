## 方块交互

| 功能 | 操作与条件 |
| --- | --- |
| 铁门与铁活板门 | 创造模式右键切换开关；下蹲时需主手为空。能力默认开启，可在能力菜单中关闭 |
| 釉面陶瓦旋转 | 创造模式下蹲、主手为空时右键，每次水平旋转 90°。能力默认开启 |
| 双层半砖拆分 | 持半砖破坏双层半砖，只移除瞄准的半层。模式在加入时默认开启，可用 `/slab` 切换 |
| 光源亮度 | 右键光源方块，在 0–15 之间循环亮度 |
| 管理员方块 | 按保护权限放置、破坏命令方块三种、拼图、结构方块、结构空位、屏障、测试方块、测试实例方块和光源；右键禁止打开其原版界面 |

铁门与陶瓦交互需 `buildercore.ability.irondoor` / `buildercore.ability.terracotta`，以及 `buildercore.protect.interact`、`.break`、`.place`。半砖拆分需半砖命令权限和破坏权限。管理员方块仍派发放置、破坏事件，非创造模式放置会扣除物品；列表独立于 `special-items`，旧版不增加不存在的材质。

## 实体摆放与调整

以下刷怪蛋操作和动物调整均检查 `buildercore.protect.place`：

| 操作 | 当前行为 |
| --- | --- |
| 刷怪蛋右键方块 | 在方块上方生成实体，朝向玩家 |
| 刷怪蛋左键方块 | 若实体支持年龄，生成幼年实体 |
| 下蹲使用刷怪蛋 | 生成关闭 AI 的实体；非下蹲时开启 AI；生成的生物设为无敌 |
| 末影龙刷怪蛋 | 禁止使用，即使特殊物品菜单中存在该物品 |
| 左键攻击生物 | 首次提示确认，3 秒内再次攻击同一实体直接移除；盔甲架与 Display 展示实体不参与此清除逻辑 |
| 调试棒右键猫 / 下蹲右键猫 | 切换坐下状态 / 循环切换品种 |
| 调试棒右键马 / 下蹲右键马 | 循环切换花纹 / 毛色 |
| 普通木棍右键狐狸 / 下蹲右键狐狸 | 循环切换坐下、睡觉、站立 / 红狐与雪狐 |

## 坐垫修改工具

支持坐垫实体与拆除事件的 Paper 26.3 服务端可使用 `/cushiontools` 切换工具模式。原背包（含装备、副手及选中栏位）先保存到 `plugins/BuilderCore/cushiontools/inventories/<UUID>.dat`，再替换为九格快捷工具。再次执行命令退出并恢复；断线、重生、插件卸载时恢复，异常停服后在下一次加入时恢复。恢复失败会保留备份并锁定操作，请勿删除该目录。

需要 `buildercore.commands.cushiontools` 及 `buildercore.protect.interact`、`.break`、`.place`；旁观模式不可操作。工具节点默认 OP 拥有，公共及私人建筑权限包也包含该节点。权限被撤销后仍可执行命令退出。

| 快捷栏 | 操作 |
| --- | --- |
| 1–3：X/Y/Z 微调 | 指向坐垫，左键减、右键加，每次 **1/32 格**；不需要下蹲 |
| 4：准星拖动 | 右键坐垫选中，跟随准星移动；距离保持在选中时的 1–8 格；再次右键落位，左键取消并退回起点 |
| 5：连续放置 | 右键地面，每次放置一个；沿途重复点击可快速刷放 |
| 6：连续拆除 | 点击坐垫拆除，不掉落物品 |
| 7：两点框选 | 左键第一点、右键第二点，点击地面方块选取 |
| 8：吸取样板 | 点击已有坐垫，复制颜色和朝向 |
| 9：菜单 | 选择 16 种颜色及四个水平朝向，预览并确认批量放置/拆除，或退出工具模式 |

初始样式为白色、朝南。吸取样板可保留任意角度；菜单会显示当前角度。工具放置不消耗坐垫物品。普通旋风棒不再调整坐垫。

框选放置按水平范围每格一个，以第一点的方块高度为参考，在上下 8 格内按距离寻找最近的可支撑地面；距离相同时优先下方。按列中心的实际碰撞面定位，适应半砖和阶梯；无支撑、空间不足或已有坐垫则跳过。两个点的高度同时用于拆除范围：从较低点的方块底部，到较高点上方两格（不含上边界），只匹配该范围内坐垫的实体原点。

批量操作需先在菜单预览数量，再点击绿色按钮确认；红色按钮取消。预览保存待拆除坐垫的 UUID，之后新放置的坐垫不会被加入本次拆除。水平选区最多 1024 格、单次最多 1024 个，每 tick 执行最多 32 个；不加载新区块。执行时复查权限、世界、地面和目标有效性，结束后报告成功数量；离线、退出或换世界会停止剩余操作，已完成的部分保留。

工具模式禁止背包整理、丢弃、捡取、副手交换、其他命令及普通方块破坏，避免工具与原物品混用。移动与拆除跳过有乘客的坐垫。调整后的坐垫沿用原有持久标记，可悬空或嵌入方块；取消支撑丢失和阻挡导致的自动拆除，退出工具后仍可正常攻击拆除。放置和拆除会触发对应实体事件，供其他插件拦截；微调和拖动只检查上述权限、区块及世界边界，第三方区域插件对移动的额外限制需实服验证。

## 容器快速打开

持潜影盒或末影箱右键空气，需要 `buildercore.service.quickopen`。末影箱打开自己的实际库存；潜影盒为只读预览，禁止放入、取出、快捷转移和拖拽物品；预览窗口内也不能整理自己的背包。

## 环境与保护

服务器可配置拦截爆炸、树叶衰减、玩家踩踏耕地，以及部分红石、重力和其他方块物理事件，见[安装与配置](installation.md#建筑环境)。以下行为不受这些开关控制：

- 取消玩家伤害与饥饿值变化；隐藏原版加入/退出消息。启动时对第一个已加载世界关闭进度公告规则 `ANNOUNCE_ADVANCEMENTS`。
- 阻止珊瑚死亡。主手持剑时拦截方块交互、实体攻击、盔甲架操作和告示牌修改等操作。
- 缺少讲台权限时，右键有书的讲台会改为直接阅读书；告示牌、点火、物品展示框、盔甲架等另有保护节点。
- 无 `buildercore.blocked.bypass` 时，只拦截完整输入恰为 `/plugins`、`/?`、`/help`、`/bukkit` 的命令，忽略大小写；带参数或命名空间的其他写法不在此列表中。
