# 建筑交互

## 菜单

`/buildertools` 默认打开能力菜单，可切换铁门、陶瓦旋转、半砖破坏、夜视、穿墙和进阶飞行。

| 菜单 | 操作 |
| --- | --- |
| `armorcolor` | RGB 左键加 8、右键减 8、Shift 点击随机；点击护甲领取 |
| `banner` | 依次选底色、图案颜色和图案；支持随机、撤销、重置和领取，最多 16 层 |
| `special` | 点击领取配置中的特殊物品 |

菜单领取物品时，背包放不下的部分掉在脚下。菜单会话及铁门、陶瓦能力开关在离线后清理。

## 方块交互

| 功能 | 操作与条件 |
| --- | --- |
| 铁门、铁活板门 | 创造模式主手右键开关；下蹲时主手需为空，能力默认开启 |
| 釉面陶瓦 | 创造模式下蹲、主手为空时右键旋转 90°，能力默认开启 |
| 双层半砖 | 持半砖破坏时只移除瞄准的半层；加入时默认开启，用 `/slab` 切换 |
| 光源 | 主手右键循环调整 0–15 亮度，需交互和放置权限 |
| 管理员方块 | 按保护权限放置、破坏命令方块、拼图、结构方块、结构空位、屏障、测试方块、测试实例方块和光源；禁止打开其原版界面 |

铁门和陶瓦另需 `buildercore.ability.irondoor` / `buildercore.ability.terracotta`，以及交互、放置、破坏权限；半砖拆分需半砖命令权限和破坏权限。管理员方块会派发放置/破坏事件，非创造模式放置会扣物品。

## 实体摆放与调整

以下操作需 `buildercore.protect.place`；刷怪蛋和双击移除不能在旁观模式下使用。

| 操作 | 效果 |
| --- | --- |
| 刷怪蛋右键 / 左键方块 | 在上方生成朝向玩家的实体 / 支持年龄时生成幼年实体；主副手均可使用 |
| 下蹲使用刷怪蛋 | 生成关闭 AI 的生物，非下蹲时开启 AI；生成的生物设为无敌，禁止生成末影龙 |
| 连续左键生物 | 3 秒内两次攻击同一目标后移除；玩家、盔甲架和 Display 不参与，已取消的伤害不触发 |
| 调试棒主手右键猫 / 下蹲右键猫 | 切换坐下 / 循环品种 |
| 调试棒主手右键马 / 下蹲右键马 | 循环花纹 / 毛色 |
| 木棍主手右键狐狸 / 下蹲右键狐狸 | 循环坐下、睡觉、站立 / 切换红狐与雪狐 |

## 坐垫工具

在支持坐垫 API 的 Paper 26.3 服务端执行 `/cushiontools` 进入模式，再次执行退出。需要坐垫工具及交互、放置、破坏权限，旁观模式不能操作；权限撤销后仍可退出恢复背包。

原背包（含装备、副手和选中栏位）先备份，再替换为 9 格工具。退出、断线、重生或插件卸载时恢复；异常停服后下次加入时恢复。恢复失败的处理和备份位置见[备份与恢复](installation.md#备份与恢复)。

| 快捷栏 | 操作 |
| --- | --- |
| 1–3：X/Y/Z 微调 | 指向坐垫，左键减、右键加，每次 1/32 格 |
| 4：准星拖动 | 右键选中，移动准星拖动；距离为选中时的 1–8 格；右键落位，左键取消并退回起点 |
| 5：连续放置 | 右键地面放置，不消耗坐垫物品 |
| 6：连续拆除 | 点击坐垫拆除，不掉落物品 |
| 7：两点框选 | 左键第一点、右键第二点 |
| 8：吸取样板 | 点击坐垫复制颜色和朝向 |
| 9：菜单 | 选择颜色、朝向，预览并确认批量操作，或退出模式 |

初始为白色、朝南；菜单提供 16 色和 4 个朝向，吸取样板可保留任意角度。

批量操作先框选，再到菜单预览，点击绿色按钮执行或红色按钮取消。水平面积及单次数量上限为 1024，每 tick 最多处理 32 个，不加载新区块；离线、退出或换世界会停止剩余操作，已完成部分保留。

放置按水平范围每格一个，以第一点高度为参考，在上下 8 格内找最近支撑面，同距离优先下方；可适应半砖、阶梯，无地面、空间不足或已有坐垫时跳过。拆除覆盖两点水平范围，从较低点底部到较高点上方 2 格，不含上边界；只处理预览时选中的坐垫。

模式内禁止整理背包、丢弃、捡取、副手交换和其他命令。移动、拆除跳过有乘客的坐垫；调整后的坐垫可悬空或嵌入方块。放置和拆除派发保护事件，微调、拖动只检查工具权限、区块及世界边界，区域插件对移动的限制需单独联调。

## 容器快捷打开

持潜影盒或末影箱右键空气，需要 `buildercore.service.quickopen`，支持副手。末影箱打开自己的实际库存；潜影盒为只读预览，窗口内禁止取放、快捷转移、拖拽及整理自己的背包。

## 环境与保护

可配置的环境开关见[安装与配置](installation.md#配置与重载)。以下为固定行为：

- 取消玩家伤害和饥饿值变化，隐藏原版加入/退出消息；启动时关闭第一个已加载世界的进度公告。
- 阻止珊瑚死亡；主手持剑时拦截方块交互、实体攻击、盔甲架操作和告示牌修改。
- 缺少讲台权限时，右键有书的讲台改为直接阅读；告示牌、点火、展示框、盔甲架另有保护节点。
- 无 `buildercore.blocked.bypass` 时，拦截 `/plugins`、`/?`、`/help`、`/bukkit`，包括带参数或命名空间的写法，忽略大小写。
