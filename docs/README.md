# BuilderCore

BuilderCore 是面向 Minecraft 建筑服务器的 Paper 插件，提供建筑交互、装饰工具、飞行、传送和环境保护功能。

常用入口为 `/buildertools`（`/btools`）。功能是否可用取决于服务器版本、权限和已安装的插件。

| 模块 | 内容 |
| --- | --- |
| [非命令功能](features.md) | 方块交互、实体摆放、坐垫工具、容器快速打开和环境保护 |
| [命令](commands.md) | 建筑工具、玩家状态、传送、时间天气及管理命令 |
| [快捷命令](shortcuts.md) | WorldEdit 选区、复制粘贴、形变与撤销 |
| [安装](installation.md) | 运行要求、安装步骤、配置与重载 |
| [权限配置](permissions.md) | 权限包、建筑保护和家数量 |
| [插件集成](integrations.md) | MapManager v4、PlaceholderAPI、代理消息与用户协议 |
| [代码审查与风险](audit.md) | 本次修复、保留的权限边界与验证范围 |
| [开发](development.md) | 编译、检查、数据文件与错误处理 |
