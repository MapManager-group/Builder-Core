# BuilderCore

面向 Minecraft 建筑服务器的 Paper 插件，提供建筑工具、飞行、传送、物品编辑和环境保护。

| 阅读目的 | 文档 |
| --- | --- |
| 安装、配置、备份与插件集成 | [安装与配置](docs/installation.md) |
| 配置权限包和命令权限 | [权限配置](docs/permissions.md) |
| 查命令、参数和别名 | [命令手册](docs/commands.md) |
| 使用菜单、方块交互和坐垫工具 | [建筑交互](docs/features.md) |
| 编译、测试与修改插件 | [开发](docs/development.md) |

玩家常用入口为 `/buildertools`（`/btools`）；管理员可用 `/buildercore help` 查看命令目录。
